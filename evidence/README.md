# Evidence Index

This folder contains sanitized screenshots captured before paid or trial services are retired.

Evidence should show service surfaces, not private data. Each screenshot must use visible redaction where necessary and must avoid tenant URLs, real identities, service credentials, raw exports, and account subscription pages.

The public catalog in `catalog.json` tracks what each screenshot proves, whether it was captured successfully, and any service privilege boundary encountered during capture.

Raw screenshots were staged outside the repository during redaction and are not part of the project archive.
